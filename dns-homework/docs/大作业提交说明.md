# **大作业提交说明**

请各小组按照以下仓库命名、目录结构和结果文件格式提交。

# **一、Gitee 仓库命名规则**

每组只提交一个 Gitee 仓库，仓库名统一为：

<table><tr><td><p>dns-homework</p></td></tr><tr><td><p>将根据名单中的 Gitee 用户名自动生成仓库地址：https://gitee.com/用户名/dns-homework</p></td></tr></table>

- 仓库名不要添加中文、空格或其他后缀。

# **二、仓库统一目录结构**

仓库结构可参考以下目录和文件。评分程序只读取 answers 目录下的三个 CSV 文件。

<table><tr><td><p>dns-homework/<br/>├── README.md<br/>├── src/<br/>│   └── 源码<br/>├── docs/<br/>│   └── 实验报告.pdf<br/>└── answers/<br/>    ├── dns1.csv<br/>    ├── dns2.csv<br/>    └── dns3.csv</p></td></tr></table>

- answers/dns1.csv、answers/dns2.csv、answers/dns3.csv 是评分使用的唯一结果文件，其他结构仅供参考。
- 文件名和目录名必须完全一致，不要使用中文文件名、空格或额外后缀。

# **三、结果文件格式**

所有 CSV 均使用 UTF-8 编码，英文逗号分隔，第一行为表头。每个结果文件只放两列。

<table><tr><td><p><strong>任务</strong></p></td><td><p><strong>文件路径</strong></p></td><td><p><strong>表头</strong></p></td><td><p><strong>第二列含义</strong></p></td></tr><tr><td><p>DNS1</p></td><td><p>answers/dns1.csv</p></td><td><p>fqdn_no,family_no</p></td><td><p>family_no 为恶意域名家族编号，按题目训练数据中的编号体系提交。</p></td></tr><tr><td><p>DNS2</p></td><td><p>answers/dns2.csv</p></td><td><p>fqdn_no,label</p></td><td><p>label 为二分类结果，按题目训练数据中的 0/1 标签体系提交。</p></td></tr><tr><td><p>DNS3</p></td><td><p>answers/dns3.csv</p></td><td><p>fqdn_no,label</p></td><td><p>label 为聚类簇编号，例如 0,1,2,3,...；簇数不能小于 3。</p></td></tr></table>

## **提交样例**

DNS1：answers/dns1.csv

<table><tr><td><p>fqdn_no,family_no<br/>fqdn_17932,0<br/>fqdn_10055,0</p></td></tr></table>

DNS2：answers/dns2.csv

<table><tr><td><p>fqdn_no,label<br/>fqdn_6709,1<br/>fqdn_6004,1</p></td></tr></table>

DNS3：answers/dns3.csv

<table><tr><td><p>fqdn_no,label<br/>fqdn_6709,0<br/>fqdn_6004,2</p></td></tr></table>

## **注意事项**

- fqdn\_no 必须使用题目数据中的编号，不能改名。
- DNS1 的第二列命名为 family\_no，DNS2 和 DNS3 的第二列命名为 label。
- 第二列只能填数字编号，不要填中文、英文类别名或概率。
- 不认识或未提交的样本不会得分；评分程序会按已命中的测试样本比例折算。
